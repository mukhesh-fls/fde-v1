# Start here

1. Open this folder in a terminal and run `claude`.
2. Paste this first message:

> Read CLAUDE.md and every file in docs/ and content/. Then summarise in 10 lines what we're building and how a learner learns at a station. List anything unclear or that you'd change for better learning. Then start milestone M0 and M1 from docs/05-build-plan.md. Stop after M1, run it, take a screenshot and show me.

3. After each milestone, check the screenshot and say "next milestone" or give feedback.

Tip: the most important milestone is M4 (the Rebooking Desk). If that doesn't make someone understand retries just by watching, fix it before building more.
